Fanex.ConnectionString

Configuration

Add section configure configsections for Fanex.ConnectionString 

        <configsections>
            <section name="ConnectionSettings" type="Fanex.ConnectionString.Configuration.ConnectionSettings,
                Fanex.ConnectionString">
        </configsections>
Add configure ConnectionSettings 

        <ConnectionSettings Connection="Data Source=10.19.10.71;Initial
            Catalog=bodb_ConnectionString;integrated security=false; User ID=sa;Password=1234aa"
            IsLocal="false">        
        </ConnectionSettings>

Note

        
    
            
  1. Connection : Connection string of database "bodb_ConnectionString" which
                store all connection string 
    2. 
            
  2. IsLocal : If is true, will get connection string in web config
    3.
